# 核心逻辑只用标准库，唯一第三方依赖是 openpyxl

工具最终运行在公司内网的测试机上，发行版与 Python 版本不可控（openEuler 多个版本共存），pip 在外网代理下可用但在内网是否可靠未经验证。因此决定：解析、比对、报告生成全部只用 Python 标准库，语法兼容 Python 3.8~3.13；唯一第三方依赖是写 xlsx 必需的 `openpyxl`，并随代码附带 wheel 以便离线安装。理由：本项目的单次数据量只有几百到几千行，标准库完全够用，而 pandas 在 2→3 之间行为差异大、内网未必装得上。

## Considered Options

- **用 pandas**：表达力强，但引入大依赖与版本兼容风险，收益与数据量不匹配。
- **纯标准库、自己写 xlsx**：xlsx 是 zip + XML，自写实现不可维护。

## Consequences

解析器需要自己处理行解析、数值归一化与类型不一致（同一字段在不同文件里可能是字符串或数字）。
